Titmouse Bounce

Titmouse Bounce is an infinite runner game built using the Godot game engine. You play the titular titmouse attempting to collect as many seeds as possible while avoiding nuthatches! WASD to move, space to jump. Controls are rebindable in the settings. The current high score as set by my friend is 409.

The idea behind making the game was to build something that was 100% hand made. All pixel art, sound effects, music, and code was designed and written by me. You can check out the code on GitHub.

No generative AI/LLMs were used or consulted for this project.
