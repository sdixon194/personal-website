Leaderboard Application

Leaderboard (working title, work-in-progress) is a Next.js application for comparing game scores with your friends. It was conceived after starting a score-chasing arcade club with some internet friends and me wanting something slicker than a CSV to keep tabs of scores. It is currently in a pre-alpha state and is fully functional, but needs some more work before launching as a beta for others to self host themselves.

You can follow development in the GitHub repository.

No generative AI/LLMs were used or consulted for this project.
